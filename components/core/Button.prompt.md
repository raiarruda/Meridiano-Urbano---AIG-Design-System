# Button

Botão de ação principal do sistema Meridiano Urbano. Use para todas as ações iniciadas pelo usuário.

```jsx
<Button variant="primary">Salvar Configuração</Button>
<Button variant="accent" size="lg">Avaliar Imóvel</Button>
<Button variant="secondary">Ver Detalhes</Button>
<Button variant="ghost" size="sm">Limpar Filtros</Button>
<Button variant="danger" disabled>Excluir</Button>
```

## Variantes
- `primary` — Navy #002445. Ação principal de tela.
- `accent` — Amber #E87D2C. CTA de conversão na área pública.
- `secondary` — Contorno navy, fundo transparente. Ação secundária.
- `ghost` — Sem borda nem fundo. Ação terciária / inline.
- `danger` — Vermelho. Ações destrutivas.

## Tamanhos
- `sm` (32px) — ações em tabela, toolbars densas
- `md` (40px) — padrão
- `lg` (48px) — CTAs em hero / formulário público
